# 行程海报视觉检查清单

用于生成香港 VIP 行程海报、签单行程 PNG 后、推送给顾问或签单群之前。

## 必检项

1. **标题净空**
   - 顶部“香港行程安排”等主标题无遮挡。
   - VIP 标签、卡片、覆盖层不得进入标题净空区。
   - 标题必须可读，不能被浅色背景冲淡到难以识别。

2. **背景来源**
   - 如使用图片背景，先确认它是空白模板，不是旧成品图。
   - 只要底图存在旧客户名、旧产品、旧时间、旧地点、旧联系人、旧提醒，立即停止使用。
   - 若只有旧成品图，改用干净 HTML/CSS 复刻模板。

3. **旧资料残留**
   - 检查是否出现非本单客户姓名。
   - 检查是否出现旧产品、旧金额、旧签约时间、旧签约地点。
   - 检查底部、角落、半透明区域是否有旧联系人或旧提醒。

4. **重复重贴**
   - 检查同一段内容是否重复出现。
   - 检查新文字是否叠在旧文字上。
   - 检查标签、卡片、列表是否错位或重影。

5. **内容完整**
   - 标准四段必须完整显示：基础信息 / 行程安排 / 出行相关联系人 / 重要提醒。
   - 底部不得截断；尤其检查“重要提醒”最后一条是否完整显示。
   - 如内容过长，优先压缩间距与字号，不删除 FNA、本人赴港签署、如实申报、非保证收益等合规提醒。

6. **敏感信息**
   - 群发海报默认不展示完整电话号码。
   - 如必须展示联系方式，先取得顾问确认，并尽量脱敏。

7. **进度条/进度反馈样式**
   - 当顾问要求“要有进度条”时，海报顶部可加入细长圆角进度条装饰，但不得压住主标题净空区。
   - 进度条建议放在 1080×1920 画布顶部约 40px，左右留边 80px 以上，高度 12–18px，使用浅金/白色渐变，保持商务感。
   - 过程反馈可用 `⏳ 进度 n/m｜当前动作`、`✅ 进度 m/m｜视觉检查通过` 这种短消息；只在关键节点发，避免重复刷屏。

## 推送规则

- 视觉检查不通过：不推送，直接修版。
- 通过后：只推一张最终 PNG。
- 不把废稿、多版本图一起发给用户或签单群。

## 推荐检查提示词

```text
请检查这张香港行程海报是否合格：
1 顶部“香港行程安排”是否无遮挡且清晰；
2 是否无旧客户/旧工单信息残留；
3 是否无重复重贴；
4 四段内容是否完整无截断；
5 是否无完整电话号码等敏感信息。
请回答通过/不通过，并简洁列出问题。
```
