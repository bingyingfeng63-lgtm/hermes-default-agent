# 行程海报背景板使用与纠错经验

## 触发场景
用于生成香港 VIP 行程海报、签单行程海报、客户赴港行程 PNG 时。

## 关键经验
1. **优先使用用户既有 Canva/原背景板，但必须确认是“空白模板”**
   - 不要默认用临时渐变背景或自行设计全新背景。
   - 当前已知文件 `/mnt/c/Users/冯冰莹/Desktop/hermes/行程海报和缴费页面/香港VIP客户行程安排海报_1.png` 已确认是“带旧客户资料的成品海报”，不是空白模板，严禁再直接作为背景底图。
   - 若路径不确定，先搜索桌面 `*行程*`、`*海报*`、`*VIP*`，找到后先做视觉检查：必须确认没有旧客户名、旧产品、旧时间、旧地点、旧联系人、旧提醒文字，才可作为背景。

2. **禁止把带旧资料的成品图当背景板**
   - 只要底图中存在任何旧工单文字，不允许用“叠字”“遮盖”“局部清底”的方式继续生成正式海报。
   - 原因：容易混入其他客户资料，造成隐私风险和专业风险。
   - 正确处理：A 找真正空白模板；B 复刻干净模板；C 等用户提供空白 Canva 导出。默认优先 B：复刻干净模板。

3. **生成前先确认背景来源**
   - 如果用户说“生成海报”，默认含义是套用既有模板/背景板，不是重新设计。
   - 若只找到成品图而找不到空白模板，必须说明风险，并改用干净复刻模板，不得直接输出叠加版。
   - 当用户连续发送图片并说“发错了 / 是这张”时，以最后明确确认的图片为准；先检查尺寸、是否空白、是否有旧资料，再进入重排。
   - 1080×1920 的空白蓝色维港背景板可直接作为手机竖版行程海报底图；若通过文件工具显示 `.bin` 但 `file` 识别为 PNG，可按 PNG 处理。

4. **顶部标题净空是硬性要求**
   - “香港行程安排”等主标题区域必须保持净空。
   - VIP 标签、内容卡片、覆盖层不得遮挡、压住或贴近主标题。
   - 导出后必须视觉检查标题区，确认无重叠再推送。

5. **视觉检查通过后只推新版一张**
   - 用户不喜欢重复推送多张图。
   - 发现背景错误后：明确承认问题 → 找原背景/复刻干净模板 → 视觉检查 → 只推新版 PNG。
   - 检查项：无旧客户资料、无重复字段、无标题遮挡、无内容截断、无敏感电话完整展示。

6. **隐私处理**
   - 联系人电话可内部记录；群发/海报版本默认只展示姓名，除非用户明确要求展示完整电话。

## 标准模板选择（硬性规则）

**首选模板：维多利亚港背景统一风格**
- 使用王永生 HTML（`~/.hermes/cache/outputs/html/王永生-itinerary.html`）作为标准模板。
- 该模板包含：维多利亚港风景背景图（1080×1920 Base64 内嵌）、统一 CSS 样式（深蓝色模块标签、时间轴、橙色提醒卡片、铃铛图标）。
- **禁止**用 CSS 渐变的 clean-template（`itinerary-poster-clean-template.html`）替代，除非用户明确要求换风格。
- 生成方法：用 Python 读取王永生 HTML → 提取 CSS + 背景图 Base64 → 替换 body 内容为当前客户数据 → 输出新 HTML → wkhtmltoimage 渲染 PNG。
- **读取大文件技巧**：王永生 HTML 约 1.27MB（含 Base64 内嵌背景图），`read_file` 工具可能截断。改用 `execute_code` 中 Python 的 `open().read()` 直接读取全文，再用 `re.search` 提取所需部分。

### 出行相关联系人模块：2 联系人 vs 3 联系人变体

### Python 提取背景图 img 标签的陷阱 ⚠️

**错误写法（会导致空白海报）：**
```python
# 只匹配到 src 属性末尾，丢失 class="bg-image" 等关键属性
img_match = re.search(r'<img src="data:image/png;base64,[^"]*"', template)
```

**正确写法：**
```python
# 匹配完整 img 标签，包含所有属性直到 >
img_match = re.search(r'<img src="data:image/png;base64,[^"]*"[^>]*>', template)
```

**原因：** 原始模板 HTML 的 img 标签带有 `class="bg-image" alt="背景图" />`，CSS 中 `.bg-image` 定义了 `position: absolute; z-index: 0` 等关键定位属性。若正则只提取到 `src` 属性末尾，生成的 HTML 中 img 标签残缺，CSS 定位失效，背景图不显示或遮挡内容，最终渲染为空白海报。

**验证方法：** 生成 HTML 后检查 `class="bg-image"` 是否存在于 img 标签中，确认后再调用 wkhtmltoimage。

## 推荐操作流程
1. 搜索/确认原背景板。
2. 先做视觉检查，判断是空白模板还是旧成品图。
3. 如果是空白模板：可将原背景板 Base64 内嵌到 HTML，作为 `background-size: 100% 100%` 的底图。
4. 如果是旧成品图：严禁直接当底图；改为使用标准维多利亚港模板（王永生 HTML）。
5. 默认使用维多利亚港背景统一风格（王永生 HTML 模板），提取 CSS + 背景图，替换客户数据。
6. 导出 PNG 后用视觉检查确认：无旧客户资料、无重复字段、标题无遮挡、文字完整、无截断。
7. 用 `MEDIA:/absolute/path/to/png` 推送一张新版。

## 避免话术
- 不要说“这是新的设计风格”来解释偏离模板。
- 不要让用户自己再找模板，除非搜索确实找不到。
