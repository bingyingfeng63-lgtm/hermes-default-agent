# 行程海报背景板确认流程

适用场景：顾问在 WeCom 上传图片/文件作为行程海报背景板，或纠正“发错了/是这张”。

## 核心规则

1. **先验图，再生成**
   - 收到背景板文件后，先用文件识别确认真实格式与尺寸。
   - 再用视觉检查确认是否为空白模板、是否有旧客户/旧行程文字、是否有水印、标题/卡片可放区域。
   - 不要仅凭顾问一句“这个呢？”就直接生成。

2. **顾问说“发错了”时**
   - 立即停止使用上一张素材。
   - 不要继续解释上一张如何处理，避免干扰。
   - 以最新上传的图片为准重新检查，并明确“已改用这张”。

3. **优先使用标准手机竖屏背景**
   - 标准目标：1080×1920。
   - 若素材不是 1080×1920，可适配，但必须说明是否需要裁切/遮挡水印。
   - 如果新素材已经是 1080×1920 且无水印，优先使用新素材，不再用兜底模板。

4. **必须拦截旧成品图**
   - 背景图如已含旧客户姓名、旧日期、旧行程、旧二维码、完整电话等，视为旧成品图，不得作为底图复用。
   - 可建议顾问重新上传空白背景板或授权使用兜底干净模板。

5. **对外回复要短**
   - 只说明：是否可用 / 关键风险 / 下一步。
   - 不展开技术细节，不列后台文件路径，除非顾问要求。

## 推荐回复格式

```
这张是正确背景板。
- ✅ 尺寸：1080×1920，适合手机竖版
- ✅ 无旧客户/旧行程内容
- ✅ 可直接用于重排

下一步：我用这张重新生成最终版，只输出 1 张 PNG 给你检查。
```

## 检查清单

- [ ] 文件格式是图片（PNG/JPG/WebP 等）
- [ ] 尺寸记录清楚，优先 1080×1920
- [ ] 无旧客户、旧日期、旧行程、旧二维码、完整电话
- [ ] 主标题净空足够
- [ ] 内容卡片区域不会压住主体视觉
- [ ] 无水印；如有水印，已说明裁切/遮盖方案
- [ ] 生成后再做视觉检查，通过才推送单张 PNG
